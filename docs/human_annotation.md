# 视觉 QC 人工标注

## 目标

人工标注不是替模型确认答案，而是建立独立的真实参考集。第一阶段优先标注真实 fMRIPrep
输出；合成异常用于检查流程和模型敏感性，不能代替真实异常。VLM 结果默认隐藏，避免锚定偏差。

## 启动

```bash
cd /path/to/neuro_preprocess_agent
scripts/run_labeling_ui.sh \
  --manifest data/visual_qc/ten_subject_validation/manifest.jsonl \
  --predictions data/visual_qc/vlm_reviews/ten_subject_qwen25vl3b_v4.jsonl \
  --report runs/reports/run_20260914_160650_e449685f_summary.json
```

打开 `http://127.0.0.1:8502`。界面会显示结构像、功能像、运动和 fMRIPrep reportlet，
原始 T1w、原始 BOLD 时间均值，以及对应的预处理结果。数值证据包括影像维度、体素大小、
时间点、输入非零占比、脑掩膜体积、FD、DVARS、tSNR、mask Dice 和 mask fraction。
侧栏路径可换成其他批次。

原始 T1w 非零占比低于 30%，或脑掩膜体积低于当前批次中位数的 60% 时，界面只显示复核
提示，不自动生成标签。这两个阈值用于发现数据异质性和明显离群值，不是医学诊断阈值。

## 标注规则

- `原始结构像状态`：记录 `完整头部 / 面部已脱敏 / 输入已去颅骨 / 无法判断`，它是输入元数据，不是异常结论。
- `pass`：未发现会影响后续分析的明显异常，不选择异常标签，也不排除被试。
- `uncertain`：证据不足或异常较轻，需要第二人复核；必须选择相关标签并填写备注。
- `fail`：存在明确且可能影响分析的异常；至少选择一个标签并填写备注。
- `severity` 描述异常影响程度；`exclude_subject` 是下游分析排除建议，不等于删除数据。
- 先查看所有面板和定量指标并提交人工判断，再按需打开 VLM 建议进行对照。

标注写入 `data/visual_qc/labels.jsonl`。同一例重新标注会追加新记录，不会覆盖旧记录；
界面的完成进度和预填值按当前标注者独立计算，第二位标注者不会看到第一位的预填结论；
完整历史仍用于审计和一致性分析。

## 数据治理

- 标注者必须使用稳定且可区分的名字。
- `uncertain` 和 `fail` 必须写清可见证据，不能只写“有问题”。
- 合成样本在界面中使用哈希化案例编号，且不展示原始文件名或合成变换类型。
- 正常的面部脱敏不计为异常；只有脱敏区域侵入脑组织时，才使用 `coverage_error` 等异常标签。
- 建议至少两名标注者独立复核一部分重叠样本，之后计算总体决定的一致率和 Cohen's kappa。
- 训练、阈值选择和最终测试应按被试与站点拆分，禁止同一被试的变体跨集合泄漏。

## 第一批任务

先独立标注十被试真实批次。该批次规模不足以训练模型，但可以验证标签定义、界面和
`sub-04` 待复核案例。规则稳定后再扩展正常样本，并有目的地收集真实失败与边界案例。

# LLM Supervisor 回放评测（2026-10-12）

## 条件

- 模型：`deepseek/deepseek-v4-flash`
- temperature：`0`
- 数据集：30 条人工审核规划用例（dev 20、test 10）
- 重复次数：每条 3 次，共 90 次模型调用
- 执行范围：仅调用 Supervisor，不执行下载、fMRIPrep、QC 或数据库 Worker
- 评分对象：结构化输出、原始计划、安全约束后计划、受管参数和禁用动作

延迟 P50 为 2.740 秒，P95 为 4.802 秒；总 token 为 153,766，其中输入 135,549、输出
18,217。稳定性只比较计划、下一节点、跳过步骤、fMRIPrep 参数和安全约束结果，不比较自由文本
`reason`，因为解释措辞变化不改变可执行决策。

## 解释边界

该结果证明当前模型在这 30 条受约束、人工审核的规划请求上能稳定生成符合 schema 的计划，且
未调用禁用 Worker。它不证明开放域泛化、复杂运行中动态重规划、真实数据预处理成功率或 QC
模型准确率。数据集规模仍较小，后续应加入 Worker 失败 observation、QC 冲突、权限变化和模糊
多轮修改场景，并使用不参与提示词调整的新测试集复验。
